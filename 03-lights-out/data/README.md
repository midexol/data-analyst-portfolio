# Data

The raw files aren't saved in this repo. Run `bash src/get_data.sh` to download them into `data/raw/`.

- **Source:** [Our World in Data, energy dataset](https://github.com/owid/energy-data) (CC BY 4.0), pinned to commit `f8de88a`
- **Where OWID gets electricity numbers:** Ember and the Energy Institute's Statistical Review of World Energy
- **Files used:** `owid-energy-data.csv` (the data) and `owid-energy-codebook.csv` (what each column means)
